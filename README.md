# Gestão Financeira Pessoal

Aplicação em Python para acompanhar investimentos, despesas, cartões de crédito e empréstimos. Ela também reúne os gastos por mês e gera relatórios financeiros em PDF.

## Executar localmente

Instale as dependências e inicie o Streamlit:

```powershell
pip install -r requirements.txt
streamlit run main.py
```

## Executar com Docker

Com o Docker Desktop aberto, execute:

```powershell
docker compose up --build -d
```

Abra <http://localhost:8501> no navegador. O banco do Docker fica em um volume persistente. Para parar a aplicação, use `docker compose down`.
